# 第1章 | 藏锋日常

晨雾未散，杂役院的土墙上还挂着露水。空气里混着朽木、湿土和劣质朱砂的气味——这些味道他闻了太久，久到分不清是这一世的日常，还是前一世残留的惯性。

林渊将最后一叠符纸码进木匣，指尖在符面划过。朱砂纹路平滑，灵气收敛得恰到好处。七张。他默数一遍，又从袖口抽出两张压在匣底。九张。够交这个月的贡献点，还能余两张换疗伤散。

前世他交七张。刚好压线，因为那时候他真的只能画七张。

“林渊。”功德堂执事的声音从院门口传来，不咸不淡，“今日交兑。”

“来了。”

他抱起木匣走出杂役房。远处演武场传来内门弟子的早课呼喝，金属撞击的脆响混在其中。林渊没往那边看，沿着墙根的阴影走。青石板被露水浸得发黑，中间一道被无数杂役弟子踩出的浅槽，像刻在石头上的命轨。

功德堂门可罗雀。门槛磨得光滑发亮，门内飘出陈年账册的霉味。执事接过木匣，逐张验看符纸，干枯的手指在纸面反复按压。验到第八张，眉头微动。

“这个月多交两张。”

“想换一瓶疗伤散。”

执事没多问。魔门功德堂从不多问，只记账。玉简上刻下数字，刻刀划过玉面的声音尖锐短促。柜台下摸出个白瓷瓶推过来，动作行云流水。

“下月初五前，下月贡献点足额。”他抬起眼皮看了林渊一眼，“欠缴过三日，入执法堂。”

林渊接过瓷瓶。瓷壁冰凉，手感熟悉得让人胃里发紧。前世他欠缴过一次——腿断了画不出符，第三日就被执法堂带走。没审，直接关进暗牢。理由是“占用宗门资源无用者当清退”。

后来是顾小萤用三条情报换来的保人，把他从暗牢里捞出来。三条情报的价码，够买一个底层杂役弟子的命。

他把瓷瓶收进袖口，转身时手指无意识地按在胸口。

那里什么都没有。光滑的皮肤，平稳的心跳。前世胸口曾留有一道旧痕，位置他记不清了，只记得每次想起来，胸口都会隐隐发紧。

“林师兄！”

脆生生的声音从回廊方向传来。林渊脚步一顿，侧头。

顾小萤从转角处探出半个身子，杏色短衫衬得人更娇小。她左右扫了眼，确认功德堂执事没跟出来，才小跑到林渊跟前。手里攥着的玉简捏得指节发白。

“你交完这个月的了？”

“嗯。”

“够吗？”

“够。”

顾小萤咬了下唇，那颗小虎牙压在唇肉上，松开时留下一道浅浅的白印。她把玉简递过来：“你看看这个。”

林渊没接。

他低头看着眼前这个小师妹——前世，她在绝境中把唯一的逃生路线塞给他，自己留在了原地。有些债不是欠了才要还，是见过一个人在最暗的时候还亮着，就再也做不到视而不见。

所以这一世她递来的东西，不能随便接。接了，就是债。而前世欠下的，还没还完。

“是什么？”

“情报网顺手截到的。”顾小萤把玉简往他手里塞，指尖碰到他掌心时微微发凉，“有人在外围情报节点传密信，加密手法很老，一看就是内部人。我解了一层——”

她顿住，像在斟酌措辞。

“里面还有一层。”

“内容。”

顾小萤的声音压得更低：“‘查圣女血脉之源，溯源上三代。寒字部执行。’后面跟了一串暗码，我没破完。”

林渊捏住玉简。

他没有注入灵力查看，只是攥在手心。玉简的温度很低，低得像从井底捞上来的石头。寒字部。内部人。溯源三代。这三组词拼在一起，指向一个他不愿在这个时间点看到的方向。

“为什么给我？”

“因为我怕。”

顾小萤抬起头。她的眼睛亮得不太正常——不是哭过，是把恐惧压成亢奋的亮。像一个人在黑暗中待了太久，终于找到一点可以确认自己不是独自一人的证据。

“这封密信走的不是正式情报通道，是绕过监管在外围节点传的。能绕过我布下的第一层网的——”她的声音断了一瞬，“至少是堂主级。他们在查寒霜姐姐。”

林渊沉默了两息。

前世这时候，他没有收到任何预警。苏寒霜的血脉被查，是几个月后的事。但此刻任何过度的反应都会暴露他知道得太多。

“你告诉我这个，”林渊将玉简递回去，“想要我做什么？”

顾小萤没接。

她盯着林渊。那目光不像在看一个杂役弟子——太认真了，认真到林渊几乎能听见她没说出口的话。三息后，她开口。

“我观察你很久了。”

梧桐叶落在两人之间的青石板上，轻得没有声音。

“你画符的效率比表面修为高至少三成，但你每次都只交刚够用的点数。”她顿了顿，声音里多了一层连她自己都可能没察觉的紧张，“你也在藏。”

林渊没有否认，也没有承认。他只是维持着递出玉简的姿势，等她把话说完。

“我不问你在藏什么。”顾小萤说，“我只想问——如果有一天有人要查你身边的人，你会不会出手？”

林渊将玉简收回袖口。

“我收下。但我不会深究，也深究不了。”他的声音很平，“你我都知道，能绕过你外围网的，不是我们能碰的盘子。”

“我知道。”顾小萤松了口气，肩膀微微下沉，“我不让你查。我只是想……你能知道就行。知道有人在查她。”

她转身要走，走出两步又回头。那双过分明亮的眼睛里，恐惧和亢奋同时消退，剩下一种更复杂的东西——像一个人把最重的东西交出去之后，留在掌心的那点空落。

“林师兄，你这个人很奇怪。明明每天只做杂役，但对什么都好像不意外。”

她停了一拍。

“我不是在夸你。”

没等林渊回答，她就跑远了。杏色短衫在回廊尽头一闪，消失在转角。脚步声很快被风吹散，像一片叶子落进井里，响了一下就没了。

林渊站在回廊下，袖中玉简贴着腕侧。冰凉感渐渐变成灼热。有人在查圣女血脉，寒字部执行，绕过正式情报网。这个手法让他感到不安，不是因为陌生，而是因为某种说不清的熟悉感——像见过类似的痕迹，却想不起在哪里。

但他不能追溯。

因为他一旦出手查，就会暴露自己不是普通符纸杂役。而暴露的结果，前世已经演示过一遍。那一遍就够了。

远处传来脚步声。林渊收起思绪，沿回廊朝杂役房走去。

穿过丹房外的空地时，他脚步微滞。

苏寒霜站在丹房台阶上。

她今日穿的是银纹玄袍，腰束墨玉带，长发仅以一根银簪松松挽起。晨光落在她侧脸，将下颌线条勾勒得清晰冷硬。丹房门内飘出药香——苦艾、玄参，还有几味林渊叫不出名字的灵药。她没看任何人，只是垂眼瞧着手中玉简，像刚从丹房出来，在此处稍作停留。

但林渊走过时，她的视线抬了起来。

那道目光很轻。从他身上掠过，没有停留。

林渊肩背的肌肉本能地绷紧。那不是恐惧，是身体先于意识的反应——像猎物经过猛兽领地时，脊椎自主拉直的警觉。

整个过程不超过三次呼吸。

然后她垂下眼，继续看手中玉简。从头到尾，她的表情没有任何变化，像在查验一件尚未决定是否入账的货物。但那种审视本身，已经是一种标记。

林渊没停步。心跳不变，步幅不变。他穿过空地，走进对面的杂役廊道。直到转过两个弯，确认那道目光不再跟随，才缓缓吐出一口气。

右肩的肌肉还在微微发僵。他强迫自己放松，却意识到这是个好掩护——一个经历过旧伤的人，肩背本就不该太稳。下次经过丹房，可以让右肩再僵一点。刚好。

他在心里记下一笔：一个月内，再将符纸成色压低一成。效率压回表面修为能匹配的量级。

回到杂役房，林渊将门闩好。

床板硬，被褥薄。他在床沿坐下，从袖中取出顾小萤的玉简，又将自己的白瓷瓶摆在枕边。两样东西并排放着——一瓶疗伤散换两条命，一条情报欠三个人。前世他欠顾小萤三条命，最后只还了一条。这个账他一直记着，不是因为数字，是因为每次想起，胸口都会隐隐发紧。

玉简贴在额前，灵力注入。

信息碎片零散涌入意识——大部分是情报网拦截的原始信号残片，顾小萤已做初步过滤。中间一段暗码闪烁不定，她在上面留了标记：寒字部执行，查圣女血脉，溯源三代。

暗码末位还有一串连顾小萤都没标识的残余符纹。

林渊反复看了那些残符三遍。

瞳孔微缩。

那些残符的末端有一处极细微的顿笔痕迹——起笔压得太重，收笔提得太快，在符纹末梢留下一个几乎不可见的回勾。

这种笔法他总觉得眼熟，像在哪里见过类似的痕迹，但记忆碎得太厉害，拼不出完整的画面。只知道这种回勾很不寻常，不是随意书写留下的。至于出自谁手，从何而来，他追溯不了。残符就是残符，信息太少。

顾小萤解不开是对的。

林渊将玉简从额前取下，手背青筋凸起，又缓缓松开。

守护欲像一根烧红的铁棍捅进胸口。如果能提前知道是谁在查——如果能现在就掐断这条情报线——

不能。

他不能现在出手。

现在修为不过炼气七层。哪怕藏在底下的前世战斗记忆能让他越阶杀人，宗门内还有筑基十二层坐镇，有执事团虎视眈眈，有内部审查机制时刻筛除异常个体。一旦暴露，死的不只是他。

顾小萤的逃生路线、苏寒霜的挡刀机会——全都会因为他的提前暴露而化为乌有。

藏锋是底线。不是懦弱。是时间差。

林渊将玉简塞进枕下，拿起白瓷瓶倒出一粒疗伤散吞下。药力化开时微微发苦，像前世记忆留在舌根的味道，怎么咽都咽不干净。他坐在床沿，让那股苦味慢慢消散，让心跳慢慢落回平稳。

暗语预警指向内部高层，涉及圣女血脉调查。他现在能做的是三件事：保持藏锋日常，维持顾小萤的庇护意向不被她转向别人，确保苏寒霜对他的评估停留在“值得观察但不构成威胁”。

三件事互为前提。缺一件，满盘皆输。

窗外日头升高，杂役院又响起零星的脚步声。有人去交贡献点，有人在井边打水，有人在墙根下低声抱怨。伙房的烟囱开始冒烟，柴火味混着粗粮的香气飘过来——那是杂役弟子早饭的味道，糙米煮得半生不熟，用大锅闷出来的。前世他在杂役院住了三年，每天早晨都是这股味儿。没变过。唯一变的是，那时候吃饭的人里，有些已经不在了。

这种平常像一层薄冰，踩在上面的人都知道下面是深的，但没人往下看。

林渊站起来，走到桌前，铺开新的符纸。

他调了半盏朱砂，研墨时手腕刻意压低了灵力输出。这次画的是最低阶的净尘符，灵气纹路比往常更松散，成色比早上那批压了一成。画完十张，拆掉最差的三张。剩下的七张正好匹配一个普通炼气七层杂役弟子的效率——不多，不少，刚刚够活着。

他将拆掉的三张揉碎，扔进废料篓。纸团在篓底弹了一下，不动了。

窗外，一道银纹玄袍的身影穿过杂役院外的长阶。没有停留，没有侧目。

林渊没有抬头，继续画下一张。

他想起前世临死前。顾小萤跪在血泊里，苏寒霜挡在崖边，厉寒的掌风带着血腥气扑面而来。三幅画面压在胸口，沉得像三块碑。碑上刻的不是名字，是欠下的、没还完的、还不了的东西。

这一世，他藏锋。

不是不护。是为了能护到活下来的那一天。

日色西斜时，他收好符纸，将枕下玉简取出又看了一遍。残符的顿笔痕迹仍在，那个回勾刻在符纹末梢，像一枚倒计时。他将玉简放回原处，推门出去打水。

走廊尽头的铜镜映出他的脸——十七岁，面目平淡，修为平平。像任何一个在魔门底层挣扎求活的杂役弟子，丢进人堆里找不出来。

镜中人眼神很沉。那种沉法不属于十七岁。

傍晚的风穿过杂役院，吹得门页吱呀作响。远处功德堂的灯火亮起，有人正在核对今日交兑记录。伙房烟囱再次升起炊烟，在暮色中散成模糊的灰。那股熟悉的柴火和粗粮味飘过来，和早晨一模一样。林渊站在走廊上多闻了一会儿——前世从暗牢里被捞出来那天，回到杂役院闻到的第一样东西就是这个味道。那时候顾小萤还活着，苏寒霜的修为还没跌落。还能闻到炊烟。

他端着水盆走过长廊，推开自己的房门。

桌上符纸被夜风吹动一角，压在下面的玉简纹丝不动。

他放下水盆，坐在床沿，将白瓷瓶的盖子旋紧。九张符纸换一粒疗伤散，换取延续生存的权利。这个规则他一直懂。前世不懂的是，活着不是目的。

活着闻到炊烟才是。

但炊烟升起之前，他必须藏好刀。

夜深。

魔门内各处灯火渐次熄灭，只有巡逻弟子的灵石提灯在黑暗中移动，像几颗孤零零的星子。那些光点沿固定路线游走，照亮一段墙根，又把它交还给黑暗。

林渊躺在床上，没有闭眼。

枕下玉简的凉意透过枕芯渗过来。暗码末位的顿笔痕迹还在他视野里残留——那个回勾，似曾相识，却拼不完整。记忆的碎片就是这样，该清晰的时候模糊，想追溯的时候断掉。

他前世胸口曾留有一道旧痕。位置记不清了，只记得它存在过。不是皮肉的痛，是更深层的——现在这道痕还没出现，但每次想到某些事，胸口仍会隐隐发紧。这种发紧，更像是记忆刻在骨头里的标记。

窗外，巡夜弟子的提灯从走廊尽头掠过，光斑扫过窗纸，又沉入黑暗。杂役院彻底静下来，只剩下夜风穿过廊檐的细响，和远处某只夜鸟低低的啼鸣。

今夜没有动作。今夜只藏。

但藏不是什么都不做。藏是把该记的记下，该等的等住，该护的人放在心里，然后在天亮之前，让自己还活着。
