1.不知晓。2.留到章节阶段。3.留到正文。

## 章节大纲稿
- 第1章 / 藏锋日常建立，三人关系初现 / 隐藏实力与守护欲冲突 / 贡献点即命价；顾小萤截获含大师姐暗语的情报碎片 / 林渊确立苟道，苏寒霜冷眼评估，顾小萤以情报换庇护 / 预警浮现：有人在查圣女血脉，暗语指向内部高层 / 承接卷一藏锋目标；暗语为第6章假消息预置追踪链
- 第2章 / 情报债初建，大师姐压力显形 / 林渊克制出手冲动，身体出现短暂灼痛 / 情报网运作机制；苏寒霜首动圣女身份挡内部盘查 / 林渊欠下情报债，苏寒霜标明庇护的交易性质 / 线人尸首送回，伤口残留大师姐一脉功法痕迹 / 灼痛为魔痕前兆；笔迹习惯为第6章假消息预置线索
- 第3章 / 厉寒联姻通牒，前世记忆触发 / 厉寒公开婚约，苏寒霜被置二选一绝境 / 婚约实为血脉诅咒献祭；触发条件为遭遇前世死亡关联者 / 林渊从犹豫到动用记忆；苏寒霜觉察反常，怀疑其隐藏深度 / 记忆碎片涌入：前世被厉寒所杀临终画面 / 魔痕灼痛关联死亡记忆，为卷间钩子“梦中面孔”预置
- 第4章 / 情报破局，魔痕初现 / 林渊揭露婚约真相，需掩饰信息来源 / 厉寒真正目标为苏寒霜血脉中始祖遗物 / 苏寒霜欠下情报债，三人利益共生正式绑定 / 婚事暂缓，内部怀疑滋生；林渊臂上浮现第一道魔痕 / 大师姐密信厉寒“找到魔痕源头”；魔痕首次暴露完成
- 第5章 / 信任磨合，前世因果浮现 / 苏寒霜追问来源，林渊以藏锋逻辑周旋 / 前世师兄之死与厉寒关联的碎片记忆 / 苏寒霜从算计者转向困惑观察者，觉察魔痕与寿元隐约关联 / 苏寒霜：“秘密我买了，代价是下次别瞒我”；她暗中销毁林渊残留魔气痕迹 / 情感锚点为第7章抉择铺垫；师兄魔痕相似经历关联前世因果闭环
- 第6章 / 大师姐操控初现，魔痕二次暴露 / 顾小萤情报网接假密报引林渊出手救人 / 大师姐反向植入假消息手法：截获污染情报链 / 顾小萤情报自信受挫，隐瞒自查；发现线人伤口与假消息源头一致 / 林渊出手暴露魔痕位置；天刑司锁定气息现魅影宗外围；灼痛频率与追踪距离关联 / 假消息机制为裂痕埋根；魔痕二次暴露完成
- 第7章 / 苏寒霜挡追查，弧光转折兑现 / 天刑司追至外围，林渊魔痕灼痛加剧，需抉择藏或救 / 揭示天刑司法器对魔痕锁定机制：灼痛频率即定位信号 / 苏寒霜以圣女身份挡追查，修为跌落小境界；主动向林渊确认交易继续 / 苏寒霜违反利益计算不弃子；林渊感知猎杀逼近可量化 / 完成算计者到守护者转折；魔痕定位机制为后续追踪升级预置
- 第8章 / 裂痕滋生，情报债信用危机 / 顾小萤发现情报异常系大师姐操控，但隐瞒自查证明自己非累赘 / 大师姐操控升级：直接栽赃顾小萤线人与正道有染 / 顾小萤隐瞒致三人内部信息不对称；对苏寒霜生隐性比较与愧疚并存 / 苏寒霜觉异常但信任刚建立选择不逼问；林渊感知裂痕无力弥合 / 内部裂痕为卷二末主动出卖埋情感炸弹；栽赃手法延续大师姐操控线
- 第9章 / 厉寒亲至，魔痕锁定升级 / 大师姐传回魔痕位置，厉寒准备亲自出手验证 / 厉寒以猎杀者身份入场，目标锁定林渊魔痕持有者身份 / 林渊梦中前世死亡面孔清晰为厉寒；苏寒霜觉察厉寒目标转移警觉升级 / 厉寒密令大师姐制造内部混乱掩护抓捕；林渊感知猎杀逼近时间窗口压缩 / 直面厉寒压迫为卷二高潮预演；魔痕三次暴露节奏启动
- 第10章 / 坦白与抉择，卷二高潮 / 林渊向苏寒霜坦白记忆消耗与魔痕因果关系 / 信任终极考验：苏寒霜在知道代价后继续守护或止损退出 / 苏寒霜选择不弃子，完成守护者蜕变；林渊从理性守护向信任过渡 / 三人信任初步建立但魔痕位置已被厉寒锁定；寿元债首次引发记忆缺失 / 明确卷二胜果为信任建立；记忆缺失为卷三代价升级预置
