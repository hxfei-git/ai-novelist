## 阶段记忆
### 方向定位（locked）
- 一句话梗概：一名重生回魔门的主角，带着前世记忆在残酷环境里低调求生，一边小心发育，一边护住身边想护的人，日常轻松里藏着持续的危险感。
- 核心卖点：重生魔门、谨慎苟活、前世记忆带来的先手感，叠加轻松日常与暗线危机的反差。
- 主类型：重生修真 / 魔门生存 / 轻松向成长。
- 子类型 / 题材元素：日常、护短、隐忍发育、关系互动、危机暗线。
- 读者预期：既能看日常里的轻松和暧昧感，也能看到魔门环境下的谨慎博弈与自保压力。
- 目标读者：喜欢重生流、魔门背景、低调发育、人物互动和护短氛围的读者。
- 故事承诺：看主角如何凭前世记忆在危险环境中稳住自己，慢慢变强，尽量不失去身边的人。
- 表层主题：谨慎求生，低调发育，护住重要的人。
- 深层命题：在残酷环境里，仍然保留对人的在意与守护欲。
- 价值取向：不莽撞，不逞强，先保全自己，再尽力保全身边人。
- 主角原型：重生后在魔门中步步谨慎的生存型主角。
- 初始处境：身处残酷的魔门环境，手里只有前世记忆这类可用优势。

- 一、世界核心设定：来源：前序方向定位与当前已有内容。世界名暂定为“幽罗界”，是一座魔门势力压过正道、凡俗王朝依附宗门求存的修真世界，故事发生在旧秩序尚未彻底崩坏、资源却已经开始紧绷的年代。
- 一、世界核心设定：来源：当前已有内容。故事主舞台落在幽罗魔宗外门小院、药田、矿坑、边境城与近海海市；这里有热汤、糖糕、晒药竹匾，也有夜里被拖走的弟子留下的冷铁味。
- 二、世界格局：来源：当前已有内容。主线格局收束为“一洲一海”：内陆魔宗、边境城、矿脉、凡城与近海海市共同构成主要地图，外海只作为遥远边界和传闻背景。
- 二、世界格局：来源：当前已有内容。大洲腹地是幽罗魔宗灵脉核心，越往外围越接近外门小院、药田、矿坑、凡俗城镇、边境缓冲城和海港，资源逐层稀薄，规矩却越来越硬。
- 六、世界规则：来源：当前已有内容。灵气、煞气、血、魂和因果都能真实作用于修士，修行留下的气味、伤痕、梦魇与寿元亏空很难彻底抹去。
- 六、世界规则：来源：当前已有内容。死亡后的魂魄可以被封、养、炼或送渡，但每一种处理都要付出代价，强行留魂会让活人被阴寒、幻听与梦中旧债纠缠。
- 七、力量体系：来源：当前已有内容。力量主要来自炼气、炼煞、血脉、功法传承、丹药、符阵、法器和灵材，魔门路线进境快，但暗伤、心魔与反噬也更明显。
- 七、力量体系：来源：角色短评。强者尺度暂定为金丹可镇外门，元婴可压一城，但越往上越怕因果旧债与资源断供，真正稳定的强者也离不开势力供养。
- 八、成长体系：来源：当前已有内容。境界沿用引气、筑基、金丹、元婴、化神、返虚、合道的阶梯，每一层都要面对资源、心性、旧伤和时机的共同限制。
- 八、成长体系：来源：当前已有内容。突破通常需要功法、丹药、实战、闭关环境和前置资源配合，失败轻则掉境伤魂，重则经脉断裂、识海受损，前路被封。
- 十一、资源体系：来源：当前已有内容。硬资源包括灵石、丹药、灵材、符纸、法器、海货、矿料与洞府，软资源包括情报、名额、船位、护身关系和安全时间。
- 十一、资源体系：来源：当前已有内容。灵脉、药田、矿坑、海路和旧遗迹都是稀缺点，谁能接近这些地方，谁就更有机会活得久一些。

### 故事流程（locked）
- 故事从幽罗魔宗外门小院的轻松日常切入。来源：已锁定世界观与方向定位。小院里有热汤、糖糕、晒药竹匾，师妹带来的邻近温度让主角短暂觉得这一世还有慢慢来的余地；但夜里被拖走的弟子、空气里残留的冷铁味，又不断提醒他，自己仍在残酷的魔门里。
- 主角开局不求出头，只想稳住外门位置，避开会暴露前世记忆的麻烦，同时尽量护住师妹，不让她卷进外门的清洗、差役和资源争夺。来源：已锁定方向定位、人物关系与当前阶段已有内容。
- 前世记忆先表现为细小的先手感：他知道某些药田差事容易死人，知道矿坑相关任务不能轻接，也知道有些看似便宜的丹药、符纸和人情日后可能索命。来源：已锁定世界观中的药田、矿坑、丹药、符纸、软资源。具体事件细节待确认。
- 开局失败风险主要落在三处：主角被人看出“知道得太多”；师妹因靠近主角而被牵连；圣女注意到主角的异常，把他从外门日常里拎进更高压的视线。来源：已锁定人物关系与当前阶段已有内容。
- 主线从“避开危险”逐渐转向“不得不处理危险”。来源：当前阶段已有内容。外门小院、药田和矿坑的压力慢慢连在一起，主角发现自己避开的并不是零散灾祸，而是魔宗资源紧绷下的一轮清洗、争夺或试探。来源：已锁定世界观中的资源紧绷、外门小院、药田、矿坑。具体清洗形式待确认。
- 师妹线成为主角无法继续只顾自保的牵引。她可能因为一次差事、一次资源分配、一次无意听见的消息，靠近了主角原本想绕开的危险。来源：已锁定人物关系中“师妹提供日常温度与安全感”，以及方向定位中的“保护身边的人”。具体触发事件待确认。
- 中段反转落在“前世记忆失准”。主角以为自己提前避开了某个危险，却发现这一世有人提前动手、有人换了路线，或者圣女的介入改变了原本结果。来源：当前阶段已有内容与角色短评建议。这里不把失准写成新规则，只作为人物选择和局势变化带来的偏差。
- 这次失准让主角留下痕迹：他躲得太巧，救得太准，沉默得太早，反而引来怀疑。来源：当前阶段已有内容与伏笔 Agent 建议。之后他不能只靠前世记忆求生，必须把情报、人情、护身关系和安全时间一起用上。来源：已锁定资源体系中的软资源。
- 圣女线在中后段压上来。来源：已锁定人物关系。她不是单纯庇护主角的人，而是带来危险同盟感的人：她可能看中主角的谨慎、情报嗅觉或异常判断，把他放到更接近内层资源与暗线的位置。来源：当前阶段已有内容。她的具体身份细节与势力目标待确认。
- 主角此时面对的压力不再只是“不要被发现”，而是“被看见之后如何活下去”。来源：当前阶段已有内容。他既要压住自己前世记忆的痕迹，又要避免师妹被当成他的软肋，还要判断圣女抛来的机会里藏着多少代价。
