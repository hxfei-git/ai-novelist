## 故事流程稿

### 开局压力

故事从幽罗魔宗外门小院的轻松日常切入。来源：已锁定世界观与方向定位。小院里有热汤、糖糕、晒药竹匾，师妹带来的邻近温度让主角短暂觉得这一世还有慢慢来的余地；但夜里被拖走的弟子、空气里残留的冷铁味，又不断提醒他，自己仍在残酷的魔门里。

主角开局不求出头，只想稳住外门位置，避开会暴露前世记忆的麻烦，同时尽量护住师妹，不让她卷进外门的清洗、差役和资源争夺。来源：已锁定方向定位、人物关系与当前阶段已有内容。

前世记忆先表现为细小的先手感：他知道某些药田差事容易死人，知道矿坑相关任务不能轻接，也知道有些看似便宜的丹药、符纸和人情日后可能索命。来源：已锁定世界观中的药田、矿坑、丹药、符纸、软资源。具体事件细节待确认。

开局失败风险主要落在三处：主角被人看出“知道得太多”；师妹因靠近主角而被牵连；圣女注意到主角的异常，把他从外门日常里拎进更高压的视线。来源：已锁定人物关系与当前阶段已有内容。

### 中段升级

主线从“避开危险”逐渐转向“不得不处理危险”。来源：当前阶段已有内容。外门小院、药田和矿坑的压力慢慢连在一起，主角发现自己避开的并不是零散灾祸，而是魔宗资源紧绷下的一轮清洗、争夺或试探。来源：已锁定世界观中的资源紧绷、外门小院、药田、矿坑。具体清洗形式待确认。

师妹线成为主角无法继续只顾自保的牵引。她可能因为一次差事、一次资源分配、一次无意听见的消息，靠近了主角原本想绕开的危险。来源：已锁定人物关系中“师妹提供日常温度与安全感”，以及方向定位中的“保护身边的人”。具体触发事件待确认。

中段反转落在“前世记忆失准”。主角以为自己提前避开了某个危险，却发现这一世有人提前动手、有人换了路线，或者圣女的介入改变了原本结果。来源：当前阶段已有内容与角色短评建议。这里不把失准写成新规则，只作为人物选择和局势变化带来的偏差。

这次失准让主角留下痕迹：他躲得太巧，救得太准，沉默得太早，反而引来怀疑。来源：当前阶段已有内容与伏笔 Agent 建议。之后他不能只靠前世记忆求生，必须把情报、人情、护身关系和安全时间一起用上。来源：已锁定资源体系中的软资源。

### 后段冲突显形

圣女线在中后段压上来。来源：已锁定人物关系。她不是单纯庇护主角的人，而是带来危险同盟感的人：她可能看中主角的谨慎、情报嗅觉或异常判断，把他放到更接近内层资源与暗线的位置。来源：当前阶段已有内容。她的具体身份细节与势力目标待确认。

主角此时面对的压力不再只是“不要被发现”，而是“被看见之后如何活下去”。来源：当前阶段已有内容。他既要压住自己前世记忆的痕迹，又要避免师妹被当成他的软肋，还要判断圣女抛来的机会里藏着多少代价。

后段压力从外门生存扩展到边境城、矿脉或近海海市方向。来源：已锁定世界观中的“一洲一海”、边境城、矿脉、近海海市。具体主战场待确认。主角前期攒下的旧人情、情报、避开的差事、欠下的债，会在这里集中显影。

### 终局方向

本阶段终局方向暂定为“外放反击”。来源：主线结构 Agent 建议与当前阶段已有内容。主角被迫离开单纯的小院苟活状态，进入边境城、矿脉或近海海市中的一处高压场域，把前期积攒的软资源拿出来换安全时间。

终局不宜写成主角正面碾压魔门，而应落在谨慎求生后的有限胜利。来源：已锁定方向定位中的“不莽撞，不逞强，先保全自己，再尽力保全身边人”。他护住师妹，稳住自己没有被完全拆穿，同时也欠下圣女人情，进入更危险但资源更多的位置。

终局余味应保留轻松日常与危险感的反差。来源：已锁定核心卖点。小院里的热汤、糖糕和晒药竹匾可以在后段被重新看见，但它们不再只是安稳日常，而是主角付出代价后暂时守住的东西。

### 伏笔布置与回收方向

药田伏笔：前期写差事换人、药田异味、某些弟子回避特定活计。来源：伏笔 Agent 建议与已锁定世界观中的药田。中后段回收为主角提前避开的危险之一，也成为他“知道得太多”的痕迹。具体危险形式待确认。

矿坑伏笔：前期写矿坑名额异常、有人抢着去或怕着去、相关人情忽然变得便宜。来源：伏笔 Agent 建议与已锁定世界观中的矿坑、软资源。后段回收为资源争夺或外放冲突的入口。具体矿坑事件待确认。

丹药与符纸伏笔：前期写主角拒绝某些便宜丹药、符纸或人情，旁人只觉得他胆小。来源：已锁定世界观中的丹药、符纸、软资源。中段回收为前世记忆带来的先手感，同时也让旁人怀疑他判断过准。

师妹伏笔：前期用日常接触写她靠近主角带来的温度，也埋下她容易被牵连的风险。来源：已锁定人物关系。中段回收为主角不能继续单纯躲避的理由。

圣女伏笔：前期不急着让她直接庇护主角，而是让她从主角的异常痕迹里逐步注意到他。来源：人物关系中“圣女提供高压拉扯与危险同盟感”，以及伏笔 Agent 建议。回收点落在她确认主角不是普通外门弟子，却暂时不揭穿，而是把他推入更高压的位置。

前世记忆失准伏笔：前期用差事换人、路线变化、某些人提前动手等细节铺垫。来源：节奏悬念 Agent 与伏笔 Agent 建议。中段回收为主角判断第一次明显偏离前世，迫使他从“记得结局”转向“重新判断眼前的人”。
