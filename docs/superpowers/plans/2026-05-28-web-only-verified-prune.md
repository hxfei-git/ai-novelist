# Web-Only Verified Prune Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove or reclassify Web-only cleanup candidates only when import, runtime, compatibility, and test evidence prove the change is safe.

**Architecture:** This plan treats pruning as an evidence-gated sequence, not a name-based delete pass. Each candidate gets a focused check first, then either a deletion commit or a documented retain decision in `docs/web_only_reference_matrix.md` and `docs/SESSION_SUMMARY.md`.

**Tech Stack:** Python 3.11+, pytest, local file-backed `LocalStore`, package data prompts, Web-only CLI surface.
