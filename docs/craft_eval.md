# Author Craft Eval

自动评测重点：

- StageCraftBrief 包含 expected facets。
- StageCraftBrief 不包含长原文。
- 低强度 Pacing Target 不建议硬钩子或重大反转。
- `craft_mode=off` 时上下文不注入有效作者构思参考。
- Similarity Guard 能把明显复制标为 high risk。

人工评分维度：

- 真实作者构思感：1-5
- 原创性：1-5
- 阶段相关性：1-5
- Pacing Target 对齐：1-5
- 冲突质量：1-5
- 人物动机质量：1-5
- 信息释放质量：1-5
- 复刻风险：low / medium / high
